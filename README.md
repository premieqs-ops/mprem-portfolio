# M Prem — Premium Personal Portfolio & CMS

A production-oriented, premium personal brand website for **M Prem** (Digital Marketing & Business Growth Professional, Chennai).

## Stack

- **Next.js 15** (App Router) + TypeScript
- **Tailwind CSS** — custom design system
- **Framer Motion** — animations & micro-interactions
- **Lucide React** — icons
- **Supabase-ready** architecture

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Admin: [http://localhost:3000/admin/login](http://localhost:3000/admin/login)  
Dev login: any email + password `admin`

## Deploy

Already linked to Vercel. Push to `main` triggers automatic deployment.
